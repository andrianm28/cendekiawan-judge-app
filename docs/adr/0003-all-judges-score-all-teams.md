# 3. Every judge scores every team; the category's judge breaks a tie

Requested by Elite Academy on 14 Oct 2026, replacing "one judge per group".

All five judges score all 20 teams. A team's final is the average of the judges' unrounded finals, rounded half-up once (ADR 1). This removes the main weakness of ADR 2, where each category had a different judge and the cross-category order was hard to compare.

Each judge still owns one category. When the top finals in that category are equal, and only once every judge has submitted all four of its teams, that judge picks the winner on their tablet (the operator can record the pick for them). The earlier D1-then-D4 rule no longer decides category winners; the screen shows D1 and D4 averages to inform the pick. A pick only applies while the picked team is still among the tied teams, so a later correction that breaks the tie overrides it. The result cannot be locked while a category tie has no pick.

The operator runs the stage: sets the running order, puts one team on stage and starts the pitch timer (server time). Tablets open the team on stage automatically and show the same timer, so judges only score. Closing now applies per category, for every judge.
