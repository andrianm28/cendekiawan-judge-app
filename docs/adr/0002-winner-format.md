# 2. Category winners, then Rank 1–5 by final

Locked by Elite Academy on 14 Oct 2026, following the APU showcase precedent: each category's top team wins it (matching the five per-category certificates), and the five winners are ordered by final into Rank 1–3, Emerging Innovator (4) and Rising Innovator (5). Each category is scored by a different judge, so the cross-category order is only a proposal; judges confirm or reorder it in deliberation with a logged reason. Per-judge statistical normalisation was rejected because four teams per judge is too few to be stable.

Update (ADR 3): every judge now scores every team, so finals are averaged across all five judges; reordering in deliberation stays available.
